#### Key points

- Аутентификация отвечает на вопрос 'Кто ты?' (проверка подлинности пользователя).
- Авторизация отвечает на вопрос 'Что ты можешь делать?' (проверка прав доступа к ресурсам).

- JWT-токен состоит из заголовка, подписи и payload, где подпись гарантирует целостность данных.
- В payload токена не должны храниться чувствительные данные (пароли, паспортные данные), только идентификаторы и роли.
- Refresh Token используется для автоматического продления времени жизни Access Token без участия пользователя.
- Рекомендуется использовать двухфакторную авторизацию с TOTP вместо SMS для большей безопасности.
- Keycloak рекомендуется для инфраструктурных задач в Kubernetes, тогда как IdentityServer устарел.

#### Key points

- Гипотеза — это предположение, которое проверяется с помощью статистического анализа на основе выборки данных.
- Выборка используется, когда анализ всей совокупности данных (популяции) невозможен из-за объема или стоимости.
- Нулевая гипотеза (H0) — это первичное предположение, которое мы пытаемся опровергнуть или подтвердить.
- Альтернативная гипотеза (H1) — это противоположное утверждение, принимаемое при отвержении нулевой гипотезы.
- При тестировании возможны два исхода: отвержение нулевой гипотезы или нехватка доказательств для её отвержения.
- Существует два метода проверки гипотез: метод критических значений и метод P-значения.
- В методе P-значения рассчитывается Z-score, и если P-значение меньше 0.05, нулевая гипотеза отвергается.
- Уровень значимости (критическая область) обычно принимается равным 5% (0.05).
