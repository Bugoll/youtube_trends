#### Short summary

Рассматриваются продвинутые темы: доказательства нулевого разглашения (ZK), гомоморфное шифрование и вычисления с несколькими участниками (MPC) для обеспечения конфиденциальности данных.

#### Key points

- Шифрование является отдельным инструментом безопасности, не зависящим от распределенных реестров.
- Безопасность RSA основана на экспоненциальной сложности факторизации больших целых чисел.
- Метод Диффи позволяет использовать открытые ключи для шифрования без обмена секретов заранее.
- Алгоритм ЭльГамаля использует проблему дискретного логарифма в циклических группах.
- Схема Шнорра обеспечивает цифровые подписи с возможностью верификации авторства и целостности.
- Постквантовые алгоритмы (RLWE) устойчивы к атакам благодаря использованию полиномов с ошибками.
- Гомоморфное шифрование позволяет выполнять операции над зашифрованными данными без расшифровки.
- MPC позволяет вычислять функции от секретных данных, не раскрывая их участникам.
