#### Key points

#### Key points

- Автодифференцирование позволяет находить зависимость выходных данных от входных без необходимости вручную выводить формулы производной или подбирать шаг аппроксимации.
- Прямой режим автодифференцирования реализуется с помощью дуальных чисел, где значение функции и её производная хранятся в одной структуре (паре).
- При умножении дуальных чисел член со степенью epsilon^2 обнуляется благодаря свойству ε²=0.
- Для получения градиента по конкретному аргументу необходимо занулить компоненту производной, соответствующую этому аргументу в начальном состоянии.
- Обратный проход автодифференцирования требует протаскивания градиента из выходной функции обратно к входным параметрам через цепное правило.
- Сложность реализации обратного прохода на исходном коде высока, поэтому используются вычислительные графы в библиотеках типа Candle для нейросетей.
- STD AutoDiff — это экспериментальная API автодифференцирования в Rust, реализованная через плагин Enzyme для LLVM, которая работает с оптимизированным кодом после первой стадии компиляции.
