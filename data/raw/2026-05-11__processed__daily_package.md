### 34. Kubernetes Project for Beginners | Run your First App on Kubernetes | Edureka | Kubernetes Live

- Channel: edureka!
- URL: https://www.youtube.com/watch?v=zTeV7mJ6feU
- Recommended action: watch
- Watch priority: 0.8

#### Short summary

Видео объясняет, почему традиционное развертывание приложений неэффективно и как контейнеры решают проблемы изоляции. Затем рассматривается роль Kubernetes как оркестратора для обеспечения высокой доступности и автоматического восстановления при сбоях узлов.

#### Key points

- Kubernetes — это оркестратор контейнеров, называемый 'K8s' из-за восьми символов между K и S.
- Традиционный метод развертывания (один сервер на приложение) приводит к высоким затратам и долгому времени на создание инфраструктуры.
- Запуск нескольких приложений на одном сервере без изоляции приводит к конфликтам портов и зависимостей.
- Контейнеры — это изолированная среда, где приложение и его зависимости работают отдельно от других приложений.
- Kubernetes решает проблему единой точки отказа (SPOF), распределяя приложения по нескольким узлам.
- Оркестратор автоматически восстанавливает сервисы при падении узла без ручного вмешательства.
- Для создания кластера на GCP используется команда 'gcloud container clusters create'.
- В продакшене рекомендуется использовать кластеры с несколькими узлами для отказоустойчивости.
- Kubernetes использует контейнерный движок containerd, а не Docker.
- Для создания объектов в Kubernetes используются YAML-файлы.
