#### Key points

- REST API использует методы HTTP для управления ресурсами через единый endpoint.
- Swagger генерируется автоматически из кода разработчика и является актуальным контрактом.
- Статус-коды ответов делятся на категории: 2xx (успех), 3xx (редирект), 4xx (ошибки клиента) и 5xx (ошибки сервера).
- В Postman существуют три вида переменных: коллекционные, окружения и глобальные.
- Глобальные переменные следует использовать только для констант.
- Переменные в Postman регистрозависимы; 'Name' и 'name' — разные переменные.
- Базовый URL (base URL) следует указывать без слэша в конце.
- Пре-реквест скрипты выполняются перед отправкой запроса для подготовки данных, например авторизации.
- Пост-респонс скрипты позволяют редактировать данные ответа после получения их от сервера.
- Для нагрузочного тестирования рекомендуется использовать профильные инструменты типа Gmet.
