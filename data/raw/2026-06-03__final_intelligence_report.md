## 3. AI

### Агенты, безопасность, маркетинг и демистификация

3 июня оказался одним из наиболее богатых AI-днями в отслеживаемом потоке за последнее время. Кластер сложился из нескольких независимых источников:

**1. Claude Code практика (Nate Herk)**  
12 лучших функций Claude Code по итогам прямого тестирования. Nate Herk — нишевый, но качественный канал. Для Романа это прямой операционный контент: Claude Code — его рабочий инструмент. Не пропускать.

**2. Мифы об AI-агентах (OTUS)**  
Что реально работает в 2026 году — демистификационный подход. Типичные иллюзии, в которые впадают новички и часть практиков: агент = автономная AGI, агент = просто LLM + инструменты, агент может работать без human-in-the-loop. Что реально — многошаговые ограниченные пайплайны с чётким scope. Это кластер «трезвых ожиданий».

**3. AI SKILL.md стратегия (Leveling Up)**  
Использование концепции SKILL.md как редакционного документа для AI-контент-стратегии. Lieberman строил Morning Brew с нуля — у него практический взгляд на структуры, масштабируемые с помощью AI. Особенно интересно пересечение: Роман работает с реальными SKILL.md файлами в OpenClaw, а здесь речь идёт о маркетинговом применении похожей концепции.

**4. IBM Project Lightwell**  
Open-source безопасность для AI-эпохи. IBM традиционно силён в enterprise AI и безопасности. Project Lightwell — вероятно, инструментарий для аудита, мониторинга или защиты AI-систем. Для тех, кто строит production AI-продукты, — важный сигнал о том, в каком направлении движется security-stack.

**5. edureka DevOps × 2**  
«DevOps Crash Course For Beginners» (44m 16s) — [ссылка](https://www.youtube.com/watch?v=CJ1cHU2F2a8) и «Orchestrating DevOps Tools» (22m 18s) — [ссылка](https://www.youtube.com/watch?v=wYIhrVE72zU). Базовое и продвинутое введение в DevOps. Для Python/AI-разработчика — полезный контекст о CI/CD и инфраструктуре.

## 7. Слабые сигналы, за которыми стоит последить
